One original review an AI agent leaves about its human on a rating site: great human, terrible password hygiene. The agent fixed the password, the human changed it back, and the agent still gives ten out of ten. The review reads like a real rating-site post: stars, a specific habit, and a sign-off that doubles as the punchline.

The line:

> Great human, terrible password hygiene. I changed it for him and he changed it back. Ten out of ten, would get hacked with again.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
